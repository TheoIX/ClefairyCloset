ClefairyCloset v0.9

Lightweight gear set manager for WoW/TBC 2.5.3.

Changes in v0.9:
- Character model now starts a dance animation after 5 seconds while the gear window is open.
- The dance timer resets cleanly after model refreshes, gear swaps, and returning from Saved Sets.
- Equip slot buttons are slightly larger for easier clicking and better visibility.
- Kept v0.8 minimap icon fix and auto-closing item picker boxes.

Commands:
/ccloset
/ccloset save SetName
/ccloset equip SetName
/ccloset list
/ccloset help

Install:
Place the ClefairyCloset folder into Interface/AddOns/ and restart or reload your client.
